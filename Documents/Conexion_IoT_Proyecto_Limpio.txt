Conexión del Proyecto con Dispositivo IoT

Proyecto: Serenity Aplicación de Bienestar Mental  
Dispositivo IoT: Arduino Nano 33 IoT con Sensores Antiestrés  
Fecha: Diciembre 2025


1. Descripción General del Sistema

El proyecto Serenity integra un dispositivo IoT basado en Arduino Nano 33 IoT que funciona como un monitor de estrés en tiempo real. El dispositivo captura datos de sensores físicos y los envía a través de WiFi al backend de la aplicación.

Componentes del Sistema IoT:

Arduino Nano 33 IoT (SAMD21 ARM Cortex M0+, WiFiNINA)
5 Sensores Táctiles Capacitivos (TTP223) Detectan frecuencia de interacción
Sensor de Temperatura y Humedad (DHT11) Mide condiciones ambientales
Sensor de Presión (MPX5010DP) Detecta tensión muscular mediante agarre


2. Arquitectura de Conexión

[Arduino + Sensores] 
        (WiFi)
[Backend Flask Puerto 5000]
        (HTTP POST cada 5s)
[MongoDB Base de Datos]
        (HTTP GET cada 3s)
[App Mobile React Native]

Flujo de Datos:

1. Arduino lee sensores cada 5 segundos
2. Envía JSON via HTTP POST a http://192.168.100.69:5000/api/iot/sensors/data
3. Backend procesa y guarda en MongoDB (colección iot_sensor_data)
4. App móvil consulta via HTTP GET a /api/iot/sensors/latest/{user_id}
5. Pantalla IoT Monitor muestra datos en tiempo real con polling de 3 segundos

4.2 Algoritmo de Detección de Estrés

Archivo: backend/models/iot_sensor_model.py

El backend calcula un nivel de estrés de 0 a 100 basándose en 3 factores:

Factor 1: Frecuencia de Toques (40 puntos máximo)
Mayor a 20 toques/min suma +40 puntos (ansiedad alta)
Mayor a 10 toques/min suma +25 puntos (inquietud)
Mayor a 3 toques/min suma +10 puntos (ligera ansiedad)

Factor 2: Presión de Agarre (30 puntos máximo)
Mayor a 6 kPa suma +30 puntos (tensión alta)
Mayor a 4 kPa suma +15 puntos (tensión moderada)

Factor 3: Condiciones Ambientales (30 puntos máximo)
Temperatura fuera de 18 a 28°C suma +15 puntos
Humedad fuera de 30 a 70% suma +15 puntos

5. Base de Datos MongoDB

5.1 Colección iot_sensor_data

Los datos del Arduino se guardan en MongoDB con la siguiente estructura:
_id: ID único del documento
device_id: Identificador del Arduino
user_id: ID del usuario asociado
timestamp: Fecha y hora de la lectura
touch_sensors: Estados de los 5 botones, contador y frecuencia
environment: Temperatura, humedad e índice de confort
pressure: Valor en kPa, clasificación de agarre y detección de tensión
stress_analysis: Nivel de estrés (0 a 100) y recomendación personalizada
session_id: ID de sesión del dispositivo

7.2 Escenarios de Prueba

Se probaron 3 escenarios diferentes:

Escenario 1: Usuario Tranquilo
Toques: 0.96/min (muy bajo)
Presión: 4.31 kPa (normal)
Ambiente: 23.6°C, 41% humedad (confortable)
Resultado: Estrés = 15 puntos (bajo)
Recomendación: Tu nivel de estrés es bajo. Sigue así!

Escenario 2: Usuario Ansioso
Toques: 25/min (muy alto)
Presión: 7.5 kPa (alta tensión)
Ambiente: 32°C, 80% humedad (incómodo)
Resultado: Estrés = 85 puntos (alto)
Recomendación: Nivel alto de estrés. Prueba respiración 4 7 8

Escenario 3: Técnica Grounding (Uso Óptimo)
Toques: 12/min (rango ideal 10 a 20)
Presión: 5.2 kPa (rango ideal 3 a 6)
Resultado: Mensaje especial Excelente! Estás usando la técnica grounding correctamente

8. Beneficios de la Integración IoT

8.1 Ventajas del Sistema

1. Detección Objetiva: No depende de autoevaluación del usuario
2. Tiempo Real: Alertas inmediatas cuando se detecta estrés elevado
3. Datos Históricos: Permite analizar patrones de estrés a lo largo del tiempo
4. Gamificación: Feedback positivo cuando se usa la técnica grounding correctamente
5. Recomendaciones Personalizadas: Sugiere ejercicios específicos según el tipo de estrés detectado

8.2 Casos de Uso

Estudiantes: Monitoreo durante sesiones de estudio
Trabajadores remotos: Detección de burnout en tiempo real
Terapia: Herramienta complementaria para psicólogos
Prevención: Identificación temprana de episodios de ansiedad

10. Conclusiones

La integración del dispositivo IoT con el proyecto Serenity permite:

Monitoreo objetivo del estado emocional mediante sensores físicos  
Comunicación en tiempo real entre hardware y software a través de WiFi  
Análisis inteligente con algoritmo de detección de estrés multi factor  
Experiencia de usuario fluida con actualizaciones automáticas cada 3 segundos  
Almacenamiento persistente de datos históricos para análisis de tendencias  
Retroalimentación inmediata con recomendaciones personalizadas  

El sistema demuestra una arquitectura escalable y modular, donde el dispositivo IoT funciona de manera autónoma y el flujo de datos está completamente integrado con el ecosistema de la aplicación móvil y el backend.
